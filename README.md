# Femme Fatale

مكتبة عربية رقمية فاخرة لقراءة كتاب "تصرفي كأنثى، فكري كرجل" مجاناً. موقع ثابت (HTML/CSS/JS فقط، بدون أي إطار عمل)، جاهز للنشر مباشرة على GitHub + Netlify.

## البنية

```
index.html              الصفحة الرئيسية (تعرض الكتاب الوحيد)
ad.html                 صفحة إعلانية وسيطة (تُستخدم قبل المقدمة وبين الفصول)
404.html
robots.txt
sitemap.xml
netlify.toml

assets/
  css/style.css         التصميم العام للموقع (الرئيسية، صفحة الكتاب)
  css/reader.css        تصميم صفحة القراءة (وضع داكن، حجم الخط، شريط التقدم)
  js/main.js            تفاعلات الصفحة الرئيسية (القائمة، ظهور البطاقات)
  js/reader.js           تفاعلات صفحة القراءة (الوضع الداكن، حجم الخط، شريط التقدم)

books/
  book1/
    index.html          صفحة الكتاب (الغلاف + الوصف + فهرس الفصول)
    cover.png            غلاف الكتاب
    intro.html           المقدمة
    chapter1.html ... chapter12.html   الفصول من الأول إلى الثاني عشر
    conclusion.html      الخاتمة
```

## عن الكتاب

الكتاب الوحيد المعروض حالياً هو **"تصرفي كأنثى، فكري كرجل"**، ويتكوّن من ١٤ صفحة قراءة: المقدمة، اثنا عشر فصلاً، والخاتمة. تم استخراج المحتوى من ملف PDF الأصلي وتقسيمه إلى صفحات HTML منفصلة لكل فصل، مع الحفاظ على نفس تجربة القراءة الفاخرة (RTL عربي، خط كبير مريح، وضع ليلي، شريط تقدم، أزرار التنقل بين الفصول).

## إضافة كتاب جديد

1. أنشئي مجلداً جديداً داخل `books/`، مثلاً `books/book2/`.
2. أضيفي صورة الغلاف (`cover.png` أو `.svg`).
3. انسخي `books/book1/index.html` كنقطة بداية، وعدّلي العنوان والوصف وروابط الفصول.
4. انسخي أحد ملفات الفصول (`chapter1.html`) لكل فصل جديد، وعدّلي:
   - عنوان `<title>` والوصف.
   - `book-tag` و `chapter-heading`.
   - نص الفصل داخل `<article class="chapter-text">`.
   - روابط "الفصل التالي" و"الفصل السابق" في `<nav class="chapter-nav">`.
5. أضيفي بطاقة الكتاب الجديد في `index.html` داخل `.book-grid`.
6. أضيفي روابط الصفحات الجديدة في `sitemap.xml`.

## نظام الإعلانات (Google AdSense)

- كل الوحدات الإعلانية الآن هي عناصر نائبة (placeholders) داخل `.ad-slot`.
- عند اعتماد حساب AdSense:
  1. استبدلي `ca-pub-XXXXXXXXXXXXXXXX` بمعرّف الناشر الخاص بكِ في كل ملفات HTML.
  2. استبدلي محتوى كل `.ad-slot` بوحدة `<ins class="adsbygoogle">` الفعلية.
- تدفق الإعلانات مطبّق فعلياً عبر `ad.html`: الضغط على "ابدأ القراءة" أو "الفصل التالي" يمرّ أولاً على صفحة إعلانية وسيطة قبل عرض الفصل التالي. **لا توجد أي إعلانات داخل نص الفصل نفسه.**

## Google Analytics

- استبدلي `G-XXXXXXXXXX` في `index.html` (وأضيفيه لبقية الصفحات إن رغبتِ) بمعرّف القياس (Measurement ID) الخاص بكِ.
- كل البيانات (الزوار، الدول، مصادر الزيارات، أكثر الفصول مشاهدة) تظهر فقط في لوحة تحكم Google Analytics الخاصة بمالك الموقع، ولا تُعرض أبداً للزوار داخل الموقع.

## النشر

1. ارفعي المجلد بالكامل إلى مستودع GitHub.
2. اربطي المستودع بحساب Netlify واختاري "Deploy site" — لا حاجة لأي أمر بناء (build command)، فقط تأكدي أن Publish directory يشير إلى الجذر (`.`).
3. الموقع سيعمل مباشرة بعد الرفع.

## التوسّع المستقبلي

البنية الحالية تسمح لاحقاً بإضافة:
- كتب إضافية إلى المكتبة.
- تصنيفات للكتب (فئات).
- خاصية البحث.
- الإشارات المرجعية (Bookmarks) والكتب المفضلة، عبر `localStorage` في `main.js`.
- مواضع إعلانية إضافية داخل `.ad-slot`.
